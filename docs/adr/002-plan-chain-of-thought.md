# ADR-002: Plan 步骤引入思维链与方向反问机制

## 状态

Accepted — 2026-05-26

## 背景

Step 1 Plan 需在生成三大总结章节前，增加可复盘的推理过程（思维链），并在求职方向存在矛盾、歧义或缺失时及时反问用户，避免后续 Analyze / Rewrite 基于错误前提推进。

## 决策

1. Plan 文档新增 **「零、思维链」** 章节，位于三大正文之前
2. Plan 执行分为 **推演 → 方向校验 →（必要时反问）→ 落盘** 四段
3. **阻塞级方向问题**须暂停 Plan 落盘，在聊天中反问，待用户澄清且更新 `intake/` 后再继续
4. **非阻塞疑点**写入 Plan「待确认项」，可继续落盘但不得进入 Step 2，直至用户确认

## 后果

- Plan 文档更长，但推理可追溯，便于复盘与 eval
- 方向冲突在早期暴露，减少 Rewrite 返工
- Agent 不得在存在未解决阻塞级方向问题时完成 Plan DoD
